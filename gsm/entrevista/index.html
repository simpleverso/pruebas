0. Common Data Structure Methods

A quick reference guide for common data structures and their methods in Python.

Data Structure: Array (List)

In Python, the standard array is implemented as a list. It is a dynamic array, meaning it automatically resizes itself when it gets full. They are contiguous blocks of memory, making index lookups incredibly fast.

Common Methods & Big O Complexity:

  • arr[i] (Access): Gets the element at the index. (Time: O(1))
  • arr.append(val): Adds an element to the very end of the array. (Time: O(1) amortized)
  • arr.pop(): Removes and returns the very last element. (Time: O(1))
  • arr.insert(i, val): Inserts an element at a specific index. (Time: O(N)) - Why? Because every element after it must shift over by one!
  • arr.pop(i) / del arr[i]: Removes an element at a specific index. (Time: O(N)) - Why? Because every element after it must shift back to fill the gap.
  • val in arr (Search): Checks if a value exists. (Time: O(N)) - Must scan the entire array.
  • len(arr): Gets the number of elements. (Time: O(1))
Python 
# Array (List) initialization
nums = [10, 20, 30]

# O(1) Operations
print("Access index 1:", nums[1])
nums.append(40) # Add to end
print("After append:", nums)
last = nums.pop() # Remove from end
print("Popped last item:", last)

# O(N) Operations
nums.insert(0, 5) # Insert at beginning (shifts everything right)
print("After insert at index 0:", nums)

nums.pop(1) # Remove at index 1 (shifts everything left)
print("After pop at index 1:", nums)

# Search is O(N)
if 30 in nums:
    print("Found 30!")

Data Structure: Dictionary (Hash Map)

Dictionaries are used to store data values in key:value pairs. They are highly optimized for retrieving data when you know the key.

Common Methods:

  • dict[key] = value: Adds or updates the key-value pair. (Time: O(1))
  • dict.get(key, default): Returns the value for the key. If not found, returns the default value without throwing an error. (Time: O(1))
  • del dict[key]: Removes the specified key. Throws KeyError if not found. (Time: O(1))
  • dict.pop(key, default): Removes the key and returns its value. Returns default if not found. (Time: O(1))
  • key in dict: Checks if the key exists in the dictionary. (Time: O(1))
  • dict.keys() / dict.values() / dict.items(): Returns views of keys, values, or (key, value) tuples respectively. (Time: O(1) to get view, O(N) to iterate)
Python 
# Dictionary implementation and usage
student_grades = {} # Initialization

# Add / Update
student_grades["Alice"] = 95
student_grades["Bob"] = 85
student_grades["Charlie"] = 90

print("Initial grades:", student_grades)

# Get
print("Bob's grade:", student_grades.get("Bob"))
print("David's grade:", student_grades.get("David", "Not found"))

# Check existence
if "Alice" in student_grades:
    print("Alice is a student.")

# Remove
removed_grade = student_grades.pop("Charlie")
print(f"Removed Charlie (grade: {removed_grade})")

# Iteration
for student, grade in student_grades.items():
    print(f"{student}: {grade}")

Data Structure: Stack

A Stack follows the Last-In-First-Out (LIFO) principle. In Python, lists are commonly used as stacks.

Common Methods:

  • append(item) (Push): Adds an item to the top (end) of the stack. (Time: O(1) amortized)
  • pop() (Pop): Removes and returns the top (last) item of the stack. Throws IndexError if empty. (Time: O(1))
  • stack[-1] (Peek/Top): Returns the top item without removing it. Throws IndexError if empty. (Time: O(1))
  • len(stack) == 0: Checks if the stack is empty. (Time: O(1))
Python

stack.append("Page 2")

top_element = stack[-1] if stack else None
print("Top of stack (Peek):", top_element)

# Pop
popped_element = stack.pop()
print("Popped element:", popped_element)
print("Stack after pop:", stack)

# Check if empty
is_empty = len(stack) == 0
print("Is stack empty?", is_empty)

Data Structure: Queue / Deque

A Queue follows First-In-First-Out (FIFO). In Python, you should use collections.deque (Double-Ended Queue) for O(1) operations from both ends.

Common Methods:

  • append(item): Adds an item to the right (end). (Time: O(1))
  • appendleft(item): Adds an item to the left (front). (Time: O(1))
  • popleft() (Dequeue): Removes and returns the left (front) item. (Time: O(1))
  • pop(): Removes and returns the right (end) item. (Time: O(1))
  • deque[0] / deque[-1] (Peek): Returns the front or end item without removing it. (Time: O(1))
Python 
from collections import deque

# Queue initialization
queue = deque()

# Enqueue (Add to end)
queue.append("Customer 1")
queue.append("Customer 2")
queue.append("Customer 3")
print("Queue:", queue)

# Dequeue (Remove from front)
served = queue.popleft()
print(f"Served: {served}")
print("Queue after serving:", queue)

# Peek (Front of queue)
front = queue[0] if queue else None
print("Next in line (Peek):", front)

# Add to front (Deque specific)
queue.appendleft("VIP Customer")
print("Queue after VIP arrived:", queue)

Data Structure: Set

A Set is an unordered collection of unique elements. It is highly optimized for fast membership testing and eliminating duplicate entries.

Common Methods:

  • add(item): Adds an item to the set. Does nothing if it already exists. (Time: O(1))
  • remove(item): Removes the item. Throws KeyError if not found. (Time: O(1))
  • discard(item): Removes the item if it exists. Does nothing if not found. (Time: O(1))
  • item in set: Fast membership check. (Time: O(1))
Python

Data Structure: Heap (Priority Queue)

A Heap is a specialized tree-based structure commonly used for Priority Queues. Python provides the heapq module which implements a Min-Heap using standard lists.

Common Methods (import heapq):

  • heapq.heappush(heap, item): Pushes a new item onto the heap, maintaining the heap invariant. (Time: O(log N))
  • heapq.heappop(heap): Pops and returns the smallest item from the heap. (Time: O(log N))
  • heap[0]: Peeks at the smallest item without popping it. (Time: O(1))
  • heapq.heapify(list): Transforms a populated list into a heap in-place. (Time: O(N))
Python 
import heapq

# Heap initialization
min_heap = []

# Push elements
heapq.heappush(min_heap, 5)
heapq.heappush(min_heap, 1)
heapq.heappush(min_heap, 3)

print("Heap after pushes:", min_heap)

# Peek the smallest
smallest = min_heap[0]
print("Smallest element (Peek):", smallest)

# Pop the smallest
popped = heapq.heappop(min_heap)
print("Popped smallest:", popped)
print("Heap after pop:", min_heap)

# Heapify an existing list
numbers = [9, 2, 7, 4, 6]
heapq.heapify(numbers)
print("Heapified list:", numbers)

1. Big O Notation & Complexity Analysis

Before diving into algorithms, you must know how to identify their efficiency. Big O notation expresses how the runtime or space requirements scale as the input size (N) grows.

How to Calculate Complexity

Rules for identifying Big O:

  • Drop Constants: O(2N) becomes O(N). We only care about how it scales, not exact operation counts.
  • Drop Non-Dominant Terms: O(N² + N) becomes O(N²) because as N grows large, the N² term dominates.
  • Addition vs Multiplication: If your algorithm does step A then step B, you add: O(A + B). If it does step B inside step A (nested loops), you multiply: O(A * B).
  • Space Complexity: Count the auxiliary space you allocate (arrays, hash maps) PLUS the size of the Call Stack if using recursion. Memory used to hold the input itself does not count.

Common Complexities (Best to Worst)

ComplexityNameHow to Identify It
O(1)ConstantHash map lookups, array index access, math operations.
O(log N)LogarithmicInput is cut in half every step (Binary Search, Tree traversal down a single path).
O(N)LinearA single loop through the input.
O(N log N)Log-LinearEfficient sorting algorithms (Merge Sort, Python's .sort()).
O(N²)QuadraticNested loops over the same input.
O(2^N)ExponentialRecursive algorithms where each step branches into 2 paths (e.g. naive Fibonacci, Subsets).
O(N!)FactorialGenerating all permutations of a sequence.

💡 Concept: Hash Maps vs Dictionaries vs Sets

These terms are often used interchangeably in interviews. Here is how they relate in Python:

  • Hash Map: The underlying theoretical computer science concept (an engine powered by hashing that allows O(1) average lookups).

7. Linked Lists

Python 
# Reversing a Linked List
def reverse_list(head):
    # 'prev' keeps track of the reversed portion. Initially empty.
    prev = None
    # 'curr' is the node we are currently looking at
    curr = head
    
    while curr:
        # 1. TEMPORARY STORE: Save the next node so we don't lose the rest of the list
        next_node = curr.next
        
        # 2. REVERSE THE POINTER: Point the current node BACKWARDS to 'prev'
        curr.next = prev
        
        # 3. MOVE FORWARD: Shift 'prev' to be the current node
        prev = curr
        
        # 4. MOVE FORWARD: Shift 'curr' to the saved next node to continue
        curr = next_node
        
    # When 'curr' is None, 'prev' is pointing to the new head of the reversed list
    return prev

8. Trees

Python 
class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

# Inorder Traversal (Left, Node, Right)
def inorder_traversal(root):
    res = [] # This array will store the values in order
    
    # We define a helper recursive function for Depth First Search (DFS)
    def dfs(node):
        # BASE CASE: If the node doesn't exist, stop.
        if not node: return
        
        # 1. Traverse the LEFT subtree first
        dfs(node.left)
        
        # 2. Process the CURRENT node (add its value to our result list)
        res.append(node.val)
        
        # 3. Traverse the RIGHT subtree
        dfs(node.right)
        
    # Start the recursive traversal from the root
    dfs(root)
    return res

9. Tries (Prefix Trees)

Python 
class TrieNode:
    def __init__(self):
        # Maps a character to another TrieNode. e.g. {'a': TrieNode}
        self.children = {}
        # Boolean to check if a complete word ends at this node
        self.is_end_of_word = False

class Trie:
    def __init__(self):
        # The root node is always an empty character that starts the tree
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        # Start at the root for every new word
        curr = self.root
        for char in word:
            # If the letter doesn't exist in children, create it
            if char not in curr.children:
                curr.children[char] = TrieNode()
            # Move down the tree to the child node
            curr = curr.children[char]
            
        # After inserting all characters, mark final node as end of a word
        curr.is_end_of_word = True

12. Monotonic Deque

Python 
import collections

# Sliding Window Maximum
def maxSlidingWindow(nums, k):
    res = []
    # Deque stores INDICES of array elements, not the values themselves
    # The elements inside the deque will always be strictly DECREASING
    q = collections.deque() 

    for i, num in enumerate(nums):
        # 1. MAINTAIN MONOTONIC PROPERTY:
        # If current number is bigger than numbers at the end of the deque,
        # those smaller numbers are useless (can never be max), so pop them.
        while q and nums[q[-1]] <= num:
            q.pop()
        
        # Add the current index to the right side of the deque
        q.append(i)

        # 2. REMOVE OUT-OF-BOUNDS ELEMENTS:
        # If the index at the front of the deque is outside our window 'k', remove it.
        if q[0] == i - k:
            q.popleft()

        # 3. ADD TO RESULT:
        # Once window has reached size 'k', the biggest element is always at the front.
        if i >= k - 1:
            res.append(nums[q[0]])

    return res

13. Sliding Window Technique

Python 
# Example: Longest Substring Without Repeating Characters (Variable Window)
def lengthOfLongestSubstring(s):
    # Set to keep track of characters inside our current window
    char_set = set()
    left = 0
    max_len = 0

    # 'right' pointer iterates through the string, expanding the window
    for right in range(len(s)):
        # If we encounter a duplicate character, our window is invalid.
        # Shrink the window from the 'left' until the duplicate is gone.
        while s[right] in char_set:
            char_set.remove(s[left])
            left += 1
            
        # Add the new unique character to the set
        char_set.add(s[right])
        
        # Update our max length (right - left + 1 is current window size)
        max_len = max(max_len, right - left + 1)
        
    return max_len

14. Two Pointers

Python 
# Example: Two Sum on a Sorted Array
def two_sum_sorted(nums, target):
    # Initialize one pointer at the start and one at the end
    left, right = 0, len(nums) - 1

    while left < right:
        # Calculate the sum of the elements at the two pointers
        current_sum = nums[left] + nums[right]
        
        # If we hit the target, return the indices
        if current_sum == target:
            return [left, right]
            
        # If sum is TOO SMALL, we need a bigger number. Move left pointer to the right.
        elif current_sum < target:
            left += 1
            
        # If sum is TOO BIG, we need a smaller number. Move right pointer to the left.
        else:
            right -= 1
            
    return []

15. Prefix Sum

Python 
# Subarray Sum Equals K
def subarray_sum(nums, k):
    count = 0
    current_sum = 0
    
    # Hash map to store {prefix_sum: frequency}
    # Initialize with 0:1 to account for a subarray starting from index 0 matching 'k'
    prefix_sums = {0: 1} 

    for num in nums:
        # Calculate the running prefix sum
        current_sum += num
        
        # If (current_sum - k) exists in our map, it means there is a previous 
        # chunk of the array we can chop off to get a subarray summing exactly to 'k'
        difference = current_sum - k
        if difference in prefix_sums:
            count += prefix_sums[difference]
            
        # Add the current running sum to the map for future lookups
        prefix_sums[current_sum] = prefix_sums.get(current_sum, 0) + 1

    return count

16. Kadane's Algorithm

Python 
# Maximum Subarray
def max_subarray(nums):
    # Initialize both variables to the first element
    max_current = nums[0]
    max_global = nums[0]

    for i in range(1, len(nums)):
        # KADANE'S LOGIC: At each step, we have two choices:
        # 1. Extend the previous subarray: max_current + nums[i]
        # 2. Start a brand new subarray from current element: nums[i]
        # We always pick the larger of the two.
        max_current = max(nums[i], max_current + nums[i])
        
        # Update the global max if our current contiguous sum is the highest seen
        max_global = max(max_global, max_current)
            
    return max_global

17. Binary Search

Python 
def binary_search(nums, target):
    # Initialize pointers to the start and end of the array
    left, right = 0, len(nums) - 1
    
    # Continue searching as long as the search space is valid
    while left <= right:
        # Using (left + (right-left)//2) prevents integer overflow bugs
        mid = left + (right - left) // 2 
        
        # If we found the target, return its index
        if nums[mid] == target:
            return mid
            
        # If mid value is too small, target must be on the RIGHT. Discard left half.
        elif nums[mid] < target:
            left = mid + 1
            
        # If mid value is too big, target must be on the LEFT. Discard right half.
        else:
            right = mid - 1
            
    # Target was not found
    return -1

def dfs_graph(graph, start):

    visited = set()

20. Breadth First Search (BFS)

Python 
import collections

# BFS traverses layer by layer (useful for shortest path)
def bfs_graph(graph, start):
    # Set to track visited nodes
    visited = set([start])
    
    # Use a Deque (Double Ended Queue) for O(1) pops from the front
    queue = collections.deque([start])
    
    while queue:
        # Loop exactly the number of elements in the CURRENT layer
        for _ in range(len(queue)):
            # Pop the first element in line
            node = queue.popleft() 
            
            # Look at all neighbors of the current node
            for neighbor in graph[node]:
                # If we haven't seen the neighbor, mark it visited and queue it up
                if neighbor not in visited:
                    visited.add(neighbor)
                    queue.append(neighbor)

21. Backtracking

Python 
# Example: Generate all Subsets (Power Set)
def subsets(nums):
    res = []
    
    # idx keeps track of which elements we are allowed to use
    # path is the current subset we are building
    def backtrack(idx, path):
        # 1. ADD TO RESULT: Every combination generated is a valid subset
        res.append(path.copy()) # Must copy because lists are passed by reference!
        
        # 2. ITERATE CHOICES: Try adding every available number from 'idx' onwards
        for i in range(idx, len(nums)):
            # 3. MAKE A CHOICE: Add the number to our current path
            path.append(nums[i])
            
            # 4. RECURSE: Move forward, exploring paths that include this number
            backtrack(i + 1, path)
            
            # 5. UNDO THE CHOICE (Backtrack): Remove the number to explore other paths
            path.pop()
            
    # Start recursion at index 0 with an empty subset
    backtrack(0, [])
    return res

22. Dynamic Programming

Python 
# Approach: Tabulation (Bottom-Up) Space Optimized
def climbStairsTab(n):
    # Base cases: 1 step = 1 way, 2 steps = 2 ways
    if n <= 2: return n
    
    # Instead of an entire array, we only keep track of the last two steps
    # to achieve O(1) Space Complexity.
    one, two = 1, 2
    
    for i in range(3, n + 1):
        # The current step is the sum of the ways to reach the previous two steps
        temp = one + two
        
        # Shift our variables forward for the next iteration
        one = two
        two = temp
        
    return two
